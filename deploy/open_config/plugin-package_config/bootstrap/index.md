# Bootstrap 预置插件目录

本目录用于 ZenVis 首次部署时预置插件包。首次启动时，zenvis-backend 会扫描本目录下的 `*.tar.gz` 插件包，自动创建插件记录并按标准安装流程执行安装（Meta/ClickHouse 建表、数据推送任务、MySQL 迁移、API、UI、看板、MCP、RAG、Skill、菜单）。

## 使用方式

1. 首次启动前，将插件包（`*.tar.gz`，打包规范见 `doc/03-插件开发与集成/插件包规范.md`）放入本目录；
2. 正常执行 `./zenvisctl compose up`（或 Kubernetes 部署流程）；
3. 启动后进入「插件管理」页面查看安装进度与结果。

## 一次性语义

- 全部插件包处理完成后，本目录会生成标记文件 `.bootstrap-install.flag`；
- 此后重启不会再自动安装——即使插件被卸载或删除（数据库无记录），也不会重新安装；
- 个别插件包安装失败时标记文件仍会生成，可在「插件管理」界面对该插件点击「安装」重试；
- 后续替换更高版本的插件包不会触发自动升级，升级请使用插件管理界面或插件市场。

## 重新触发

如需重新执行预置安装：删除本目录下的 `.bootstrap-install.flag` 文件后重启 zenvis-backend。已存在的插件记录会自动跳过，仅注册并安装数据库中尚不存在的插件包。

首次启动时本目录为空（或不存在）则不会生成标记文件，后续放入插件包再重启即可触发安装。
