## 第一步：元数据配置（必填）

### 1.1 原始数据样例

请提供 1-3 条真实或脱敏后的原始数据。可以是 JSON、日志行、CSV 行或字段清单。

```json
{
  "id": "",
  "event_time": "",
  "src_ip": "",
  "dst_ip": "",
  "event_type": "",
  "message": ""
}
```

### 1.2 实体与数据含义

| 项目 | 内容 |
| --- | --- |
| 数据描述 | 例如：防火墙访问日志、用户行为事件、资产信息、风险告警 |
| 是否包含多个实体 | 例如：否 / 是，包含资产、漏洞、风险事件 |
| 实体之间关系 | 例如：一条风险事件关联一个资产；不确定可留空 |

### 1.3 字段清单

| 字段名 | 样例值 | 中文名 | 字段含义 | 建议类型 | 是否展示 | 查询方式/备注 |
| --- | --- | --- | --- | --- | --- | --- |
| id |  | 唯一标识 |  | String | 是 | equal、in |
| event_time |  | 事件时间 |  | DateTime64(3) | 是 | 时间范围 |
| src_ip |  | 源 IP |  | String | 是 | equal、in |
| dst_ip |  | 目的 IP |  | String | 是 | equal、in |
| event_type |  | 事件类型 |  | String | 是 | equal、in |
| message |  | 原始消息 |  | String | 否 | match |

### 1.4 主键、排序与时间字段
