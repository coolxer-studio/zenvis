# 产品手册

> ZenVis 是面向企业级用户的配置化数据分析应用框架，提供数据接入、检索、
> 可视化、插件扩展和 AI 智能分析能力。

### 产品概述

ZenVis平台基于先进的AI大模型技术和大数据分析能力，为用户提供全方位的智能化服务。平台支持Android、iOS、Web、小程序、主机、容器、中间件、智能终端等多种平台的监测，能够应对日益复杂的应用与业务安全挑战和监管合规要求。

平台采用模块化、插件化的架构设计，具备强大的扩展能力，用户可以根据业务需求定制和扩展系统功能，实现业务场景的快速构建和部署。

### 核心功能

1. **大屏看板**
   - 支持按照客户需求定义增加自定义大屏
   - 提供直观的数据可视化展示
   - 实时监控系统状态和关键指标

2. **全局检索**
   - 支持跨模块、跨数据源的统一检索
   - 支持普通条件、受限高级 where 表达式、分页、排序和展示列管理
   - 支持个人过滤器保存、失效提示和元数据变化后的安全修复

3. **数智中心**
   - 基于AI大模型实现自然语言交互，降低用户使用门槛
   - 提供知识问答、数据接入、数据可视化、专项 Skill 和报表制作等智能化服务
   - 支持自动化处理从数据查询到风险处置的全流程
   - 通过 MCP 工具策略、对话内审批和调用审计控制 Agent 执行权限
   - 支持可定时、按优先级排队、可加载 Skill 的后台 AI分析任务

4. **插件应用系统**
   - 模块化设计，支持热插拔
   - 可根据特定业务需求定制和扩展系统功能

### 技术优势

- **多平台支持**：全面支持移动端（Android、iOS）、Web端、主机端、容器、中间件、智能终端等多种平台
- **AI驱动**：融合AI大模型技术，提供智能化分析和服务能力
- **插件化架构**：采用插件化设计，支持灵活的功能扩展
- **全流程覆盖**：涵盖数据采集、分析、策略制定、执行验证等完整流程
- **安全合规**：满足国家网络安全法、等级保护等合规要求

### 适用场景

- **多源数据分析**：通过元数据统一管理来自不同系统的数据
- **可视化与决策支持**：使用看板和报表呈现分析结果
- **智能分析**：通过 AI、MCP 和 Skill 扩展分析流程
- **定制应用**：通过插件构建独立业务能力

### 核心价值

- **降低接入成本**：通过配置和元数据快速接入新数据
- **减少重复开发**：复用检索、看板、权限和插件生命周期能力
- **提高分析效率**：以自动化和智能化方式辅助数据研判
- **支持持续扩展**：业务能力独立打包、安装和升级
