## 用途与价值

安全风险通常来自多个检测系统：漏洞扫描、基线检查、弱口令检测和攻击告警各自有一套数据。只看单个系统，很难回答“哪些资产风险最高、某类风险集中在哪些 IP、最近风险是否在增加”。

本插件用六类实体统一风险数据，并用一致的 `risk_level`、网络信息和更新时间字段做检索和统计：

- **风险统一分级**：六类风险使用同一套等级和状态语义。
- **详情可回溯**：每类风险都有独立列表和详情页，保留验证结果、验证方法和漏洞状态等字段。
- **IP 可关联**：风险 IP 命中调查可按 IP 跨实体查看风险分布。
- **态势可观察**：HTML 看板展示真实风险数据，不使用静态图表。

**适用对象**

- 安全运营人员：跟踪风险总量、等级分布和高风险资产。
- 风险管理人员：查看漏洞、基线、弱口令和攻击风险的整改进展。
- 应急响应人员：按 IP 关联多类风险，判断事件影响范围。

## 核心能力

- 六类 ClickHouse 实体，统一使用风险等级、网络信息和更新时间检索。
- Meta 为风险等级、验证结果、验证方法和漏洞状态提供候选映射。
- 所有列表以 `zenvis_id` 为平台主键，按 `update_time` 倒序。
- 弱口令字段保持隐藏，不允许复制或自动补全。
- 概览页和“安全风险态势”HTML 看板使用真实实体分析接口。
- 风险 IP 命中调查按 IP 跨六类实体检索。
- 内置模拟数据任务，包含 18 条样例，覆盖六类实体。

## 典型使用流程

1. 在[插件管理](插件管理.md)中安装插件，确认六个实体、数据表和模拟数据任务已创建。
2. 未接入真实风险数据时，先通过模拟任务检查列表、详情、IP 调查和看板。
3. 接入真实风险源时，按插件契约配置采集与入库任务，并确认风险类型和字段映射。
4. 为角色分配风险监控、IP 调查和配置菜单权限。
5. 正式数据验证通过后，在[数据推送服务](../服务管理/数据推送服务.md)中停止模拟数据任务。

## 注意事项

- 模拟数据任务直接写入 ClickHouse，只用于开发、演示和页面验收，不能替代生产风险接入。
- 样例中的弱口令只用于验证数据结构；UI 和 Meta 不展示、不复制、不补全该字段，生产环境应使用脱敏策略和受控权限。
- 风险等级和验证结果是数据源给出的结论，页面只做展示和统计，不替代人工研判。
- 页面统计来自已入库数据；采集任务停止后，概览和看板不会继续更新。

安装、升级和卸载操作见[插件管理](插件管理.md)。
