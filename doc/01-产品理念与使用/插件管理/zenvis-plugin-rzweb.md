# RzWeb 二进制逆向分析

> 在浏览器中完成二进制文件的静态逆向分析，无需在分析人员电脑上安装反汇编工具。

## 用途与价值

安全分析、样本排查和应急响应经常需要快速查看一个二进制文件的结构，但传统工具安装重、环境依赖多，也不适合把样本随意上传到外部服务。RzWeb 基于 Rizin 反汇编框架的 WebAssembly 移植，把常用静态分析能力放进浏览器：

- 分析人员打开菜单即可使用，不需要本地部署反汇编环境。
- 文件在浏览器本地处理，不上传服务器，降低样本外泄风险。
- 适合做初步判断、函数定位和字符串排查，再决定是否进入更深入的分析流程。

**适用对象**

- 安全分析人员：快速查看可疑样本的导入导出、字符串和函数结构。
- 应急响应人员：在隔离或受限环境中做初步二进制排查。
- 研发人员：分析崩溃转储、固件或第三方库的静态结构。

## 核心能力

- 反汇编与十六进制查看。
- 基于 Ghidra Decompiler 的反编译视图。
- 控制流图、函数调用关系和交叉引用。
- 字符串、导入表、导出表和段信息查看。
- 内置终端命令行，支持按地址和符号导航。
- 单页应用形式交付，通过菜单以 iframe 打开。

## 数据与页面

本插件不定义 Meta 实体、不创建 ClickHouse 表、不配置推送任务，也不提供看板。

| 入口 | 类型 | 说明 |
| --- | --- | --- |
| 二进制分析 | HTML 页面 | `/zenvis/html-page/com.coolxer.plugin.rzweb/rzweb/index.html` |

## 典型使用流程

1. 在[插件管理](插件管理.md)中安装插件。
2. 在[角色管理](../系统管理/角色管理.md)中为需要使用的角色分配“二进制分析”菜单。
3. 从左侧菜单进入 RzWeb。
4. 上传或拖入待分析的二进制文件，选择反汇编、字符串、导入导出或控制流图等视图。

## 注意事项

- RzWeb 的多线程 WebAssembly 依赖 `SharedArrayBuffer`，页面需要 COOP/COEP 跨域隔离响应头。
- 插件内置 `coi-serviceworker.min.js` 作为缓解方案，但要求页面运行在 HTTPS 或 localhost 安全上下文中，且 Service Worker 注册成功。
- 如果部署环境无法启用跨域隔离，多线程能力会降级或不可用；如需稳定支持，应在网关或反向代理层为插件页面路径添加响应头。
- 二进制文件在浏览器本地处理，不会上传到 ZenVis 服务器。
- 页面引用外部字体，离线环境会回退到系统等宽字体，不影响核心分析功能。

安装、升级和卸载操作见[插件管理](插件管理.md)。
