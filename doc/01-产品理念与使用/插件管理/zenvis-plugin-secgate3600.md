# 奇安信网神 SecGate 3600 NSG 防火墙

> 对接 SecGate 3600 NSG 防火墙的 Syslog 外发日志，把流量会话、DNS、本机终结、威胁和系统事件统一入库、检索和关联分析。

## 用途与价值

防火墙日志既有流量会话，也有 DNS、威胁和系统操作，格式和用途差异很大。如果只保留原始 Syslog，排查问题时需要在大量文本里逐条查找。

本插件按日志类型建立 8 个实体和 8 张表，对已识别类型做严格解析和字段校验：

- **流量可查**：按源/目的 IP、端口、协议、应用和动作检索会话。
- **威胁可追踪**：威胁事件单独建模，便于统计攻击类型和受影响资产。
- **系统操作可审计**：系统告警、升级、配置恢复和管理员事件分别留存。
- **IP 可关联**：在流量、DNS、本机终结和威胁日志之间做参与方 IP 统计。

**适用对象**

- 网络安全运营人员：查看会话、威胁事件和攻击趋势。
- 边界运维人员：审计防火墙系统操作和配置变更。
- 应急响应人员：按 IP 关联流量、DNS 和威胁记录。

## 核心能力

- 通过 UDP `12001` 接收防火墙 Syslog，支持 UDP/TCP 模式切换。
- 校验设备来源 IP、字段数量和字段类型，已识别类型的异常进入独立死信主题。
- 8 类日志分别写入独立 ClickHouse 表，威胁表不配置 TTL，其余七张表保留 1 天。
- 低代码应用提供八类日志列表与详情。
- IP 关联统计查询流量、DNS、本机终结和威胁日志中的参与方 IP。
- 态势总览看板展示安全事件与流量态势。
- 内置可独立停止的演示数据服务，复用正式校验和入库链路。

## 典型使用流程

1. 在部署环境中暴露 `12001/UDP`（或按需改为 TCP），并确认防火墙可以访问采集端。
2. 在防火墙上配置 Syslog 外发，指向 ZenVis 的采集地址。
3. 在[插件管理](插件管理.md)中安装插件，确认三个服务已创建。
4. 检查“SecGate 3600 NSG Kafka 校验入库”任务状态；设备未接入时可先观察演示服务。
5. 打开低代码应用或看板，检查八类日志是否正常展示。
6. 正式设备接入并验证后，在[数据推送服务](../服务管理/数据推送服务.md)中停止演示数据服务。

## 注意事项

- 未建模的官方日志类型和未知 `system` 模块只输出到 Vector 标准输出，不进入 Kafka、ClickHouse 或死信。
- 已识别类型的解析或类型转换失败会进入插件专属死信，不写入 ClickHouse。
- 正式接入前建议显式配置 `SECGATE3600_NSG_ALLOWED_SOURCE_IPS`；如果配置了明确设备地址，演示来源 IP 也需要临时加入，否则演示事件会被判为非法。
- 威胁表不配置 TTL，其余七张表按 `zenvis_insert_time` 保留 1 天；长期取证应提前规划归档。
- 演示数据为固定样例派生，不代表真实网络事件，禁止用于生产取证或长期留存分析。
- 正式设备接入后必须手动停用演示服务，插件升级或重新安装后也要确认它保持停用。
- 插件不包含动态 API、MCP 或凭据，ClickHouse 密码由部署环境覆盖。
- 上线前应使用现场设备验证 Syslog 编码、外层字段和字段数量。

安装、升级和卸载操作见[插件管理](插件管理.md)。
