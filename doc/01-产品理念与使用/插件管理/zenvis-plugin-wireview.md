## 用途与价值

排查网络问题或分析安全事件时，抓包文件往往需要在分析人员本机用专业工具打开。Wireview 基于 Wiregasm（Wireshark 的 WebAssembly 移植），把常用抓包分析能力放进浏览器：

- 无需安装 Wireshark，打开菜单即可分析。
- 抓包文件在浏览器本地解析，不上传服务器，也不写入平台存储。
- 适合快速验证协议交互、定位异常流量和分享分析结果。

**适用对象**

- 网络运维人员：排查连接失败、延迟和协议异常。
- 安全分析人员：查看可疑流量、会话内容和协议分布。
- 应用研发人员：验证客户端与服务端之间的实际报文。

## 核心能力

- 支持打开或拖入 `.cap`、`.pcap`、`.pcapng` 文件。
- 数据包列表与协议着色，快速识别流量类型。
- 数据包详情按协议树展开，逐层查看字段。
- 显示过滤器，按协议、地址、端口等条件筛选。
- 会话与流跟踪，还原一次完整交互。
- 原始字节与十六进制查看。
- 字段过滤与导出。
- 内置示例抓包文件，安装后可直接体验。

## 典型使用流程

1. 在[插件管理](插件管理.md)中安装插件。
2. 在[角色管理](../系统管理/角色管理.md)中为需要使用的角色分配“流量包分析”菜单。
3. 从左侧菜单进入 Wireview。
4. 打开本地抓包文件，或点击示例文件快速体验。
5. 使用显示过滤器缩小范围，打开数据包详情或跟踪具体会话。

## 注意事项

- 抓包文件全程在浏览器本地处理，不会上传到服务器。
- 超大 PCAP 的解析受浏览器可用内存限制，建议单文件控制在数百 MB 以内；更大规模的历史流量分析应使用服务端采集与结构化入库能力。
- 本插件不依赖 `SharedArrayBuffer`，不需要 COOP/COEP 跨域隔离响应头。
- 需要浏览器支持 WebAssembly 与 ES Module Worker，现代 Chrome、Edge、Firefox、Safari 均可。
- 页面引用外部字体，离线环境会回退到系统字体，不影响核心功能。
- 内置示例文件仅用于演示，可随包保留或删除。

安装、升级和卸载操作见[插件管理](插件管理.md)。
