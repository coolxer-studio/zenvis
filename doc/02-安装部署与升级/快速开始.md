# 快速开始

本页用于安装全新的 ZenVis 环境。已有数据的环境不要直接执行初始化，选用升级方式。

## 前置条件

Docker Compose 路径需要：

- Linux、macOS 或 Windows WSL 2；
- 64 位 `amd64` 或 `arm64` CPU；
- Docker Engine 24+ 与 Docker Compose v2（推荐），或 legacy `docker-compose` 1.29.2；
- Git、Bash、OpenSSL、tar 和 curl；
- 最低 8 核 CPU、16 GB 内存、50 GB 可用磁盘；推荐 16 核、32 GB 内存、100 GB SSD。

Kubernetes 路径另需 Kubernetes 1.28+、kubectl、Helm 3、动态存储类和镜像仓库访问能力。

## 在线一键部署

在空目录执行在线引导脚本：

```bash
curl -fsSL https://gitee.com/coolxer-studio/zenvis/raw/feature/1.0.1.alpha/quick-deploy.sh | bash
```

默认访问地址：

- Web：`http://localhost:11000`
- API：`http://127.0.0.1:11001`
- Swagger：`http://127.0.0.1:11001/swagger-ui/index.html`

默认访问用户名和密码：

- 安装过程会产生超级管理员`super@admin.com` 和 `admin@admin.com` 的密码，请保存到密码管理器。
- `init` 会生成权限为 `600` 的 `deploy/.env`，并且只在终端显示一次两个内置账号的随机初始密码。

## 基于源码的 Docker Compose 快速安装

```bash
git clone https://gitee.com/coolxer-studio/zenvis.git
cd zenvis
checkout feature/1.0.1.alpha
./zenvisctl compose init
./zenvisctl compose doctor
./zenvisctl compose up
```

如需修改版本、端口、监听地址或 AI 模型，先编辑 `deploy/.env`，再执行 `./zenvisctl compose up`。完整参数见[配置参考](配置参考.md)。

## Kubernetes 测试安装

内置依赖模式会在集群内创建 MySQL、ClickHouse、Redis、Redis Stack 和 Kafka，仅适合测试或验收：

```bash
kubectl config current-context
./zenvisctl k8s install \
  --namespace zenvis \
  --release zenvis \
  -f deploy/helm/zenvis/values-dev.yaml

kubectl -n zenvis port-forward svc/zenvis-frontend 11000:11000
```

浏览器打开 `http://localhost:11000`。生产环境不要复用 `values-dev.yaml`，请按[Kubernetes 部署](Kubernetes部署.md#生产环境外部依赖)准备独立 values 和外部依赖。

## 首次验收

至少完成以下检查：

1. `super@admin.com` 和 `admin@admin.com` 可使用安装时生成的密码登录。
2. 登录后立即修改两个账号密码，并妥善保留 API、MCP、Vectum 令牌。
3. 打开系统状态总览、全局检索、元数据配置和插件管理页面。
4. 检查后端、Vectum、MySQL、ClickHouse、Redis、Redis Stack、Kafka 和前端均健康。
5. 执行一次备份，并确认备份可读取；正式数据上线前至少进行一次恢复演练。

Compose 状态检查：

```bash
./zenvisctl compose status
./zenvisctl compose logs zenvis-backend
```

Kubernetes 状态检查：

```bash
./zenvisctl k8s status --namespace zenvis --release zenvis
./zenvisctl k8s logs backend --namespace zenvis --release zenvis
```
