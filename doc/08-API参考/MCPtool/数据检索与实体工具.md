# 数据检索与实体 MCP 工具

`RetrievalMcpTool` 当前注册 27 个工具，分为检索与 Meta、统计分析、动态实体 CRUD 三组。

所有实体和字段参数必须使用 Meta 逻辑名称。工具不接受 SQL、物理表名、物理列名或任意表达式。

## 检索与 Meta 工具

| 工具名 | 参数 | 返回 | 默认策略 | 风险 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `retrieval_search` | `request: RetrievalRequestDto` | `DataListVo` | `ALLOW` | `LOW` | 条件检索；默认 20、单次最多 50 条 |
| `retrieval_create_rule` | `request: RetrievalRuleCreateDto` | Boolean | `ASK` | `HIGH` | 创建当前用户检索规则 |
| `retrieval_update_rule` | `request: RetrievalRuleUpdateDto` | Boolean | `ASK` | `HIGH` | 更新当前用户检索规则 |
| `retrieval_delete_rule` | `request: RetrievalRuleDeleteDto` | Boolean | `ASK` | `HIGH` | 删除当前用户检索规则 |
| `retrieval_list_rule` | 无 | `DataListVo` | `ALLOW` | `LOW` | 当前用户规则列表 |
| `retrieval_list_entity` | `ruleId?: Integer` | `DataEntityResultVo` | `ALLOW` | `LOW` | 条件检索实体 Meta |
| `retrieval_list_attribute` | `entity?: String`、`ruleId?: Integer` | `DataAttributeResultVo` | `ALLOW` | `LOW` | 条件字段 Meta |
| `retrieval_list_candidate` | `attributeId: Integer`、`text?: String` | `DataListVo` | `ALLOW` | `LOW` | 字段候选值 |
| `retrieval_list_display_entity` | `ruleId?: Integer` | `DataEntityResultVo` | `ALLOW` | `LOW` | 展示实体 Meta |
| `retrieval_list_display_attribute` | `entity?: String`、`ruleId?: Integer` | `DataAttributeResultVo` | `ALLOW` | `LOW` | 展示字段 Meta |

推荐顺序：

```text
retrieval_list_entity
  → 用户或工作流锁定 entityList[].name
  → retrieval_list_attribute / retrieval_list_display_attribute
  → 锁定 attributeList[].name
  → 可选 retrieval_list_candidate
  → retrieval_search
```

`label` 只用于向用户展示，后续请求必须使用返回的 `name`。`retrieval_search.request` 至少要求 `entity` 和 `display_list`；`display_list[].attribute_list`、条件、排序字段均使用逻辑名称。

## 实体统计分析工具

| 工具名 | 参数 | 返回 | 默认策略 | 风险 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `entity_overview` | `request: OverviewQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 多实体累计量和周期对比 |
| `entity_summary` | `request: SummaryQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 单实体多指标汇总 |
| `entity_trend` | `request: TrendQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 时间趋势 |
| `entity_distribution` | `request: DistributionQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 标量字段 TopN，最大 100 |
| `entity_aggregate` | `request: AggregateQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 最多两个维度的受控聚合 |
| `entity_histogram` | `request: HistogramQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 数值直方图 |
| `entity_scatter` | `request: ScatterQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 散点图或气泡图有限取样 |
| `entity_value_statistics` | `request: ValueStatisticsQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 指定值跨字段命中统计 |
| `entity_relations` | `request: RelationQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 源字段与目标字段关系 |
| `entity_relation_timeline` | `request: RelationTimelineQueryRequest` | `AnalyticsResponse` | `ALLOW` | `LOW` | 关系分类时间轴 |

请求对象和 REST 接口使用同一模型，字段、时间范围、指标、维度和限制见 [数据检索与实体 API](/08-API参考/RestfulAPI/数据检索与实体.md#entityanalyticscontroller)。

`AnalyticsResponse` 包含：

- `meta`：查询类型、时间范围、字段、结果数量和截断标志。
- `result`：列定义和行数据。
- `echarts`：图表类型和纯 JSON `option`。

`entity_aggregate`、`entity_histogram`、`entity_scatter` 被标记为数据可视化 Agent 专属工具。`AgentMcpToolService` 会从其他 Agent 的工具集合中排除它们；数据可视化 Agent 仍需由所选 Skill 明确允许。

## 动态实体工具

| 工具名 | 参数 | 返回 | 默认策略 | 风险 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `entity_add` | `entity: String`、`data: Map` | Boolean | `ASK` | `HIGH` | 新增动态实体记录 |
| `entity_delete` | `entity: String`、`id: String` | Boolean | `ASK` | `HIGH` | 删除单条记录 |
| `entity_bulk_delete` | `entity: String`、`ids: List<String>` | Boolean | `ASK` | `HIGH` | 批量删除 |
| `entity_update` | `entity: String`、`id: String`、`data: Map` | Boolean | `ASK` | `HIGH` | 更新单条记录 |
| `entity_bulk_update` | `entity: String`、`ids: String[]`、`data: Map` | Boolean | `ASK` | `HIGH` | 批量更新 |
| `entity_list` | `entity: String`、`params: Map` | `PageRowsVo<Map>` | `ALLOW` | `LOW` | 动态实体分页；默认 20、单次最多 50 |
| `entity_view` | `entity: String`、`id: String` | `Map<String,Object>` | `ALLOW` | `LOW` | 单条记录详情 |

`id` 是 `zenvis_id` UUID。`data` 只包含 Meta 定义的业务字段，不主动写入 `zenvis_id`、`zenvis_insert_time` 或 `zenvis_update_time`。

分页参数 Map 示例：

```json
{
  "entity": "asset",
  "params": {
    "page": 1,
    "per_page": 20,
    "status": "online"
  }
}
```

工具会把 `per_page` 或 `perPage` 限制到最多 50。

## 调用示例

检索实体 Meta：

```json
{
  "ruleId": null
}
```

执行检索：

```json
{
  "request": {
    "entity": "traffic",
    "criteria_logic": "and",
    "criteria_list": [],
    "display_list": [
      {
        "entity": "traffic",
        "attribute_list": ["event_time", "addr_src", "addr_dst"]
      }
    ],
    "page": 1,
    "size": 20
  }
}
```

更新实体：

```json
{
  "entity": "asset",
  "id": "e898f699-2159-4bdb-a5a1-3abbeef1abca",
  "data": {
    "status": "offline"
  }
}
```

## 安全约束

- 工具调用前先取得 Meta，不能根据用户自然语言猜测实体或字段。
- 统计分析只走受控服务，不接受模型生成 SQL。
- 写操作默认逐次审批；审批卡必须展示实体、记录 ID 和实际字段变更。
- 批量操作前展示数量和 ID 范围，避免空列表或非预期全量修改。
- 读取结果受分页和 Agent 结果长度限制，不能通过循环规避平台上限。
