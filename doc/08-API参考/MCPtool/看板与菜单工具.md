# 看板与菜单 MCP 工具

`DashboardMcpTool` 注册 9 个工具，`MenuMcpTool` 注册 12 个工具，共 21 个。读取工具默认允许，所有创建、修改、排序和删除操作默认要求审批。

## 看板工具

| 工具名 | 参数 | 返回 | 默认策略 | 风险 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `dashboard_create` | `request: DashboardDto` | `DashboardVo` | `ASK` | `HIGH` | 创建看板 |
| `dashboard_update` | `id: Long`、`request: DashboardDto` | Boolean | `ASK` | `HIGH` | 更新看板 |
| `dashboard_bulk_update` | `ids: List<Long>`、`request: DashboardDto` | Boolean | `ASK` | `HIGH` | 批量更新 |
| `dashboard_delete` | `id: Long` | Boolean | `ASK` | `HIGH` | 删除看板 |
| `dashboard_bulk_delete` | `ids: List<Long>` | Boolean | `ASK` | `HIGH` | 批量删除 |
| `dashboard_list` | `request: DashboardSearchDto` | `PageRowsVo<DashboardVo>` | `ALLOW` | `LOW` | 分页查询 |
| `dashboard_list_all` | 无 | `List<DashboardVo>` | `ALLOW` | `LOW` | 全部看板 |
| `dashboard_view` | `id: Long` | `DashboardVo` | `ALLOW` | `LOW` | 看板详情 |
| `dashboard_type_options` | 无 | `{options:[{label,value}]}` | `ALLOW` | `LOW` | 看板类型选项 |

`DashboardDto`：

| 字段 | 说明 |
| --- | --- |
| `name`、`code` | 看板名称和业务编码 |
| `type` | 看板类型枚举 |
| `url` | 路由或外链 |
| `config_index` | 低代码配置索引 |
| `html_path` | 静态 HTML 相对路径 |
| `is_default` | 是否默认；更新为空时保留原值 |
| `source` | 来源 |

HTML 路径必须是相对路径。设置新的默认看板会替换旧默认项；批量更新不能同时产生多个默认看板。

分页示例：

```json
{
  "request": {
    "page": 1,
    "per_page": 20,
    "name": "运营",
    "url": ""
  }
}
```

创建示例：

```json
{
  "request": {
    "name": "运营概览",
    "code": "operation-overview",
    "type": "LINK",
    "url": "https://example.internal/dashboard",
    "is_default": false
  }
}
```

## 菜单工具

| 工具名 | 参数 | 返回 | 默认策略 | 风险 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `menu_create` | `request: MenuDto` | `MenuVo` | `ASK` | `HIGH` | 创建菜单 |
| `menu_update` | `id: Long`、`request: MenuDto` | Boolean | `ASK` | `HIGH` | 更新菜单 |
| `menu_bulk_update` | `ids: List<Long>`、`request: MenuDto` | Boolean | `ASK` | `HIGH` | 批量更新 |
| `menu_delete` | `id: Long` | Boolean | `ASK` | `HIGH` | 删除菜单 |
| `menu_bulk_delete` | `ids: List<Long>` | Boolean | `ASK` | `HIGH` | 批量删除 |
| `menu_update_order` | `request: MenuOrderRowDto` | Boolean | `ASK` | `HIGH` | 更新一级和二级菜单排序 |
| `menu_list` | `request: MenuSearchDto` | `PageRowsVo<MenuVo>` | `ALLOW` | `LOW` | 分页菜单树 |
| `menu_list_all` | 无 | `List<MenuVo>` | `ALLOW` | `LOW` | 全部菜单扁平列表 |
| `menu_view` | `id: Long` | `MenuVo` | `ALLOW` | `LOW` | 菜单详情 |
| `menu_parent_options` | 无 | `{options:[{label,value}]}` | `ALLOW` | `LOW` | 一级菜单选项 |
| `menu_type_options` | 无 | `{options:[{label,value}]}` | `ALLOW` | `LOW` | 菜单类型选项 |
| `menu_level_options` | 无 | `{options:[{label,value}]}` | `ALLOW` | `LOW` | 菜单级别选项 |

`MenuDto`：

| 字段 | 说明 |
| --- | --- |
| `name` | 菜单名称，必填 |
| `type` | 菜单类型 |
| `route`、`params` | 路由和类型参数 |
| `create_root_path` | 策略配置类菜单是否创建根目录 |
| `parent_id`、`level` | 父菜单和菜单级别 |
| `order_number` | 顺序 |
| `superscript` | 角标 |
| `children` | 子菜单 |
| `source` | 来源 |

非内置应用类型会使用菜单类型对应的路由。内置且不可编辑的菜单不会被更新或删除。

排序请求：

```json
{
  "request": {
    "rows": [
      {
        "id": 1,
        "name": "系统管理",
        "level": "FIRST",
        "children": [
          {
            "id": 2,
            "name": "用户管理",
            "level": "SECOND"
          }
        ]
      }
    ]
  }
}
```

## 组合调用

创建低代码应用入口时，推荐：

```text
读取/校验/写入应用配置
  → dashboard_type_options 或 menu_type_options
  → dashboard_create（如需看板）
  → menu_parent_options、menu_level_options
  → menu_create
  → dashboard_view / menu_view 复核
```

每个写工具分别触发审批。不要把配置、看板和菜单三个副作用隐藏成一条无法审查的自然语言说明。

## 安全约束

- 创建或更新前先读取类型选项，不猜测枚举值。
- 审批卡展示名称、类型、目标 URL/路由、父菜单和是否默认。
- 外链地址必须符合部署网络和内容安全策略。
- 批量操作必须展示精确 ID 列表；空列表不代表全量。
- 删除看板或菜单前检查默认项、权限树和其他引用。
