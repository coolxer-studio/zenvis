# ZenVis 1.1.5.alpha 版本发布说明

- 发布日期：2026-11-08
- Git 标签：`1.1.5.alpha`
- 对比范围：`1.1.4.alpha..HEAD`
- 发布平台：Gitee、GitHub

## 版本重点

- 完成 issue 归纳、修复、提交、推送与关闭的自动化闭环，并新增可审核的版本发布流程。
- 数据接入智能体拆分为元数据配置和数据推送服务，数据可视化拆分为临时图表、可视化应用和数据大屏。
- DIH 支持大附件和非可读文本附件，对话卡片支持 Mermaid、HTML 预览与下载。
- 修复数据大屏预览、审批、发布记录和看板路由问题，并优化智能体工作流与对话体验。

## 新增能力
- 添加issue的关闭能力（`5769fda2`）
- 实现issue到修复到提交的闭环自动化（`e86ba53c`）
- 优化数据推动服务智能体，增加校验机制约束保证生成结果正确性（`29ce84e2`）
- 数据接入智能体拆分成独立的元数据配置和数据推送服务两个智能体，数据可视化智能体拆分成临时图表、可视化应用、数据大屏三个独立的智能体（`b17d0995`）
- DIH对话附件优化，支持大附件以及非可读文本类附件（`e662dfa4`）
- 对话卡片支持对mermaid和html格式的预览与下载（`515ac3c0`）

## 问题修复
- 将数据大屏改为“模型只生成 DashboardSpec、平台统一校验、真实预览并原子发布”的闭环，同时修复了预览确认卡缺失、审批异常、发布成功记录误判及同名看板路由错选问题（`7d96e6ad`）
- 解决不弹出数据类型提示框的问题（`2caf8d5c`）
- 解决思考卡片被挤压的问题（`f14060d2`）

## 优化与体验
- 重构可视化应用为 DataAppSpec 驱动的数据应用工作流（`dfe7f3b4`）
- 完善临时图表智能体（`fd4b0909`）
- 优化元数据配置智能体生命周期：config_add 创建空文件并立即记录，config_apply 写入正文，严格加载成功后升级为应用成功；补充改名/删除流程。（`81a658d0`）
- 优化对话框样式（`d19820f6`）
- 优化数据可视化智能体（`dd6944d1`）

## 文档与工程
- 更新文档（`da0cd2ac`）
- 迁移前端项目文档到根项目的doc下，子项目不需要单独维护文档（`520c8902`）
- 更新报表智能体相关文档（`59d1c67d`）
