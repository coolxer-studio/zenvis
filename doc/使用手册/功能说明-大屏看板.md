# 大屏看板

> 大屏看板将核心业务指标以**全屏可视化**方式实时呈现，适用于指挥室、展厅、办公室电视墙等场景。  
> - 支持 16:9、4:3、21:9 等主流分辨率，自适应 1080P / 2K / 4K  
> - 自动轮播、自动刷新、离线缓存  
> - 支持嵌入外部BI工具页面

# 看板应用
这个大屏看板集成了多种功能，旨在为用户提供一个全面的系统监控和数据分析平台，帮助用户高效地管理和优化系统性能。  
支持全屏操作，默认提供一个系统状态看板，效果如下图所示：  
![](_images/大屏看板-全屏看板页.png)

**系统信息概**
- 提供系统消息总量、启动总量和设备总量的概览，帮助用户了解系统的规模和活动水平。

**系统状态监控**
- 实时显示系统的运行状态，包括当前时间、系统启动时间等基本信息。
- 提供系统运行效率的概览，包括消息接收和处理的时延等关键性能指标。

**数据分布趋势图**
- 展示不同数据源（如Android、iOS、Host等）在一天中不同时间段的分布趋势。
- 通过图表形式直观地呈现数据的变化情况，帮助用户快速识别高峰时段。

**地区和设备分布**
- 提供数据在不同地区的分布情况，如四川省、广东省、海淀区等。
- 展示不同设备类型（如Dell、Nexus、Apple、Google等）的数据分布，帮助用户了解数据的来源和分布情况。

**时间筛选功能**
- 允许用户选择查看近一天、昨天或最近7天的数据，方便用户根据不同时间范围进行数据分析。

**消息记录**
- 显示最近的系统消息记录，包括设备ID和启动时间，帮助用户追踪系统活动和事件。

## 看板类型与路由编码

看板管理支持四种类型，不同类型的必填字段不同：

| 类型 | 用途 | 必填配置 |
| :--- | :--- | :--- |
| 内置看板 `BUILT` | 前端已有固定组件的大屏页面 | 名称、类型、路由编码 `code` |
| 低代码页面看板 `LOW_CODE_PAGE` | 通过 AMIS 配置渲染页面 | 名称、类型、配置索引 `configIndex` |
| HTML 页面看板 `HTML_PAGE` | 展示静态 HTML 页面 | 名称、类型、HTML 路径 `htmlPath` |
| 外链看板 `LINK` | 嵌入外部系统或 BI 页面 | 名称、类型、URL `url` |

“路由编码”只对内置看板必填。内置看板需要通过该编码找到前端内置组件，例如当前系统总览看板使用 `msg-board`。如果内置看板的编码没有匹配到前端组件，页面会展示“内置看板不存在或未配置”的空状态。

低代码页面看板、HTML 页面看板、外链看板不需要填写路由编码，系统会优先使用看板 ID 进行选中、高亮和打开，避免多个非内置看板因为编码为空或重复导致定位错误。

## 看板抽屉交互

大屏看板左侧抽屉使用 Element Drawer 实现。用户点击左侧按钮后，抽屉从按钮位置展开；点击抽屉外区域时自动收回。该交互只调整抽出位置，不改变原有抽屉内容和视觉样式。
