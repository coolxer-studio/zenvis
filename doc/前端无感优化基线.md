- 记录日期：2026-07-17

- 类型检查：`yarn test` 通过，约 2.25 秒

## 行为基线

优化不得改变以下外部行为：

- Hash 路由地址、路由名称、菜单参数和前进后退行为。
- 登录、外部 token 登录、退出、权限菜单和登录失效跳转。
- 看板类型选择、默认看板、检索规则、策略编辑和系统信息维护。
- 低代码应用、低代码页面、外部应用、静态 HTML 与 AMIS 静态资源地址。
- DIH 新旧会话、流式回复、中止生成、附件上传、审批、图表与 HTML 预览。
- DIH 右侧数据接入、数据可视化、分析、策略处置和报表面板的事件名称与时序。
- 后端 API URL、HTTP 方法、请求字段、响应状态含义和提示文案。

## 已知工程状态

- `vue-tsc` 可运行。
- ESLint 在优化前无法启动：ESLint 7 与 `@typescript-eslint` 7 依赖不兼容。
- 项目不配置 Jest/Vitest，本轮不新增测试框架。
- iframe 与 `srcdoc` 安全策略只记录风险，本轮无兼容性证据前不改变权限。

## 优化后验证结果

- 类型检查：`yarn test` 通过，约 2.77 秒。
- ESLint：`yarn lint` 通过，无源码诊断。
- 生产构建：`yarn build:pro` 通过，最终 Vite 构建约 11.69 秒。
- `dist` 总体积仍约 95 MB；`dist/amis` 仍约 68 MB，兼容资源未被删除。
- 入口仅预加载约 0.42 KB gzip 的 Rolldown 运行时。
- 应用入口 JavaScript 约 423.08 KB gzip；连同预加载运行时约 423.50 KB gzip。
- 相比约 2.07 MB gzip 的优化前入口 JavaScript，下降约 79.5%。
- Monaco、ECharts 和 DIH 聊天主体均保留为独立异步分包，未出现在 `index.html` 的 `modulepreload` 中。
- 构建仍报告来自 `@vueuse/core`、`js-md5` 的既有第三方告警；本轮没有修改对应依赖或安全行为。
