# 运营分析知识说明

本目录是运营分析插件的专项文档入口。

- [`数据库建表.md`](数据库建表.md)：历史 ClickHouse 物理表定义，仅用于核对或人工初始化。
- [`契约矩阵与运维.md`](契约矩阵与运维.md)：实体、推送、UI、看板、环境变量、升级和故障排查契约。

插件包含十类事件实体，默认查询排序字段均为 `event_time`。列表、详情、统计和看板只使用当前 Meta 中存在的实体与字段；平台记录主键是 `zenvis_id`，业务事件编号仍为 `id`。

模拟任务是可停用的测试能力。生产环境应接入可信采集源，并保留同样的字段名、ClickHouse 类型和毫秒时间格式。
