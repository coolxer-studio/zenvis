# 风险监控契约矩阵与运维

## 实体矩阵

| 实体 | 场景 | 默认排序 | 详情页 |
| --- | --- | --- | --- |
| `risk_event` | 风险汇总 | `update_time` | `detail-event` |
| `risk_data` | 数据安全风险 | `update_time` | `detail-datarisk` |

## 数据链路

`demo_logs → 严格 JSON 解析 → risk_type 路由 → 删除路由字段 → 对应 ClickHouse 表`

`push_risk.yaml` 包含每类三条、共 18 条样例，以及合法路由和非法 JSON 两个 Vector 测试。未知字段不会被静默丢弃。生产链路应替换演示源，并保留相同字段契约。

## UI 与看板

- 低代码应用：`com.coolxer.plugin.risk`
- IP 调查页：`com.coolxer.plugin.risk.ip-statistics`
- 详情页：`com.coolxer.plugin.risk.detail-*`
- HTML 看板：`com.coolxer.plugin.risk.dashboard.risk-overview`

概览和看板只调用实体统计真实接口。旧 `/timeline` 返回随机演示序列，仅为旧调用兼容，不再由新 UI 使用。

## 安全边界

- `risk_weak.password` 的 `display_selected`、`copyable`、`auto_complete` 均为 `false`。
- 模拟密码不是生产凭据；日志、截图和导出仍应避免泄漏真实敏感数据。
- IP 调查对同一实体多个 IP 字段执行 OR 匹配，每条记录最多计数一次。

## 升级边界

1. 1.2.1 将实体 ID 固定为 `6201–6206`，字段 ID 固定为 `620001–620100`，满足跨插件全局唯一校验。
2. ClickHouse 物理结构保持不变，`sort_column: update_time` 只改变默认查询排序。
3. 1.2.0 若从未成功安装或安装已回滚，可直接安装 1.2.1；若已成功安装，必须先执行平台级 ID 迁移，普通升级不能修改既有 ID。

## 排障

- 页面 404：确认新 `site.json` 不再引用旧 edit/file/device 页面，并检查 `detail-*` 子目录已安装。
- 态势无数据：检查 Entity Analytics 权限、Meta 是否加载和各表是否有 `zenvis_insert_time` 内置字段。
- 模拟数据不入库：检查任务开关、ClickHouse 连接、Vector 错误分支和 Meta 字段一致性。
