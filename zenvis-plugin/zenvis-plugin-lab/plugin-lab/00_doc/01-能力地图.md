## 可替换点

这个插件的价值在于把每一层做成独立样例，因此可以按需替换而保留其余部分：

- 替换 `lab-demo-generator.yaml` 的生成逻辑或上游，保留 Kafka 契约、Meta 和页面；
- 以 `lab-kafka-to-clickhouse.yaml` 为生产接入模板，替换 Topic、枚举和字段；
- 以 `extend-lab` 为薄 JAR 骨架，替换 Repository 与业务服务；
- 以 `notes.json` 为 CRUD 模板，替换字段与状态机；
- 以 `lab-capability-guide` 为 Agent 导览模板，替换知识库与只读工具白名单。
