# 数据模型

Meta 文件位于 `01_meta/meta-lab.json`，使用实体 ID `9401/9402`，属性 ID 范围为 `940101–940112` 与 `940201–940211`。

## 实体与表

| 实体 | 表 | 排序字段 | 分区 | 用途 |
| --- | --- | --- | --- | --- |
| `lab_access_event` | `lab_access_event` | `occurred_at` | `toYYYYMM(zenvis_insert_time)` | 演示访问行为、枚举字典、数组、JSON 与 IP 调查 |
| `lab_risk_signal` | `lab_risk_signal` | `detected_at` | `toYYYYMM(zenvis_insert_time)` | 演示风险评分、处置状态、规则编码与跨实体关联 |

## `lab_access_event`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `event_id` | `String` | 业务唯一 ID，可复制；首字段链接到详情页 |
| `occurred_at` | `DateTime64(3)` | 业务发生时间，页面按日期展示 |
| `actor` | `String` | 用户或服务身份 |
| `action` | `String` | `login/read/write/execute/share`，字典约束 |
| `result` | `String` | `success/denied/failed`，字典约束 |
| `severity` | `String` | `info/low/medium/high`，字典约束 |
| `source_ip` | `String` | 可复制，链接到 IP 调查页 |
| `destination_ip` | `String` | 可复制，链接到 IP 调查页 |
| `resource` | `String` | 接口、页面或对象路径，可复制 |
| `trace_id` | `String` | 链路关联标识，可复制 |
| `tags` | `Array(String)` | 数组字段与标签筛选示例 |
| `detail` | `json` | 请求详情 JSON，详情页展示原文 |

## `lab_risk_signal`

| 字段 | 类型 | 说明 |
| --- | --- | --- |

| `detected_at` | `DateTime64(3)` | 线索检出时间 |
| `rule_code` | `String` | 示例规则编码，可复制 |

| `destination_ip` | `String` | 可复制，链接到 IP 调查页 |

## 字典边界

| 字段 | 中文标签与存储值 |
| --- | --- |
| 动作 | 登录=`login`、读取=`read`、写入=`write`、执行=`execute`、共享=`share` |
| 结果 | 成功=`success`、拒绝=`denied`、失败=`failed` |
| 访问风险级别 | 提示=`info`、低=`low`、中=`medium`、高=`high` |
| 线索风险级别 | 低=`low`、中=`medium`、高=`high`、严重=`critical` |
| 处置状态 | 待处理=`open`、调查中=`investigating`、已解决=`resolved`、已接受=`accepted` |

`action`、`result`、`severity`、`status` 均设置 `must_candidate: true` 和 `mapping`。页面选择器、查询条件和接入校验必须使用同一组值。

## 平台字段

插件不定义 `zenvis_id` 和 `zenvis_insert_time`。平台自动注入：

- `zenvis_id`：记录 UUID，用于详情页 `record_id`；
- `zenvis_insert_time`：平台入库时间，仅用于分区和平台查询。

Vector 转换输出不得写入这两个字段，Sink 输出集合必须与 12 个和 11 个业务属性完全一致。
