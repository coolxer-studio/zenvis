# UI 与看板

插件采用 `04_ui` 多配置目录。每个一级子目录生成独立配置索引，互不覆盖。

## 低代码应用

配置索引：`com.coolxer.plugin.lab.app`

`04_ui/app/site.json` 提供四个导航入口：

- 能力总览：`overview.json`
- 访问事件：`access-event-list.json`
- 风险线索：`risk-signal-list.json`
- 实验室笔记：`notes.json`

两个实体列表使用平台实体 API：

```text
/zenvis/api/v1/entity/lab_access_event/list
/zenvis/api/v1/entity/lab_risk_signal/list
```

列表展示业务字段、字典映射、数组/JSON 能力和安全链接；不直接访问 ClickHouse 表。

## 详情页

配置索引：

- `com.coolxer.plugin.lab.detail-access-event`
- `com.coolxer.plugin.lab.detail-risk-signal`

数据接口：

```text
GET /zenvis/api/v1/entity/{entity}/{record_id}/view
```

`record_id` 来自 Meta 首字段 `link_template` 中的 `{zenvis_id}`。详情页展示属性、JSON 原文、平台记录 ID/入库时间，以及源 IP 与目的 IP 的只读调查入口。Meta 中每条记录的详情链接和页面实体必须一致。

## IP 关联调查

配置索引：`com.coolxer.plugin.lab.ip-investigation`

支持 `?ip=` 查询参数和手工输入。页面调用：

```text
POST /zenvis/api/v1/entity/value-statistics/query
```

`mappings` 同时包含两个实体，每个实体匹配 `source_ip` 与 `destination_ip`，`criteria_logic` 为 `or`。因此同一实体中的同一记录即使两个 IP 字段都命中，也只计一次；跨实体分别计数后汇总。

## HTML 大屏

文件：`04_ui/html-page/lab-overview.html`

看板使用真实 ZenVis API：

- `/entity/overview/query`：累计与今日指标；
- `/entity/trend/query`：近 24 小时趋势；
- `/entity/distribution/query`：风险级别分布；
- `/entity/value-statistics/query`：Top 源/目的 IP；
- 两个实体的 `/list`：最新访问事件与风险线索；
- 插件 `/capabilities` 与 `/notes/stats`：能力矩阵与笔记状态。

页面包含加载、空数据、部分失败提示、重试、最后更新时间、手动刷新、60 秒自动刷新倒计时，以及页面隐藏时暂停刷新。页面按 iframe 嵌入设计，根高度来自容器而不是 `100vh`，长列表在面板内部滚动。

## 看板注册

`05_dashboard/config.json` 注册两个看板：

| 名称 | 类型 | 关键配置 |
| --- | --- | --- |
| 插件能力实验室大屏 | `HTML_PAGE` | `html_path: lab-overview.html` |
| 插件能力实验室数据观察台 | `LOW_CODE_PAGE` | `config_index: com.coolxer.plugin.lab.dashboard` |

低代码看板目录必须为：

```text
05_dashboard/low-code/com.coolxer.plugin.lab.dashboard_config/
```

HTML 路径只填写相对 `04_ui/html-page/` 的文件名，不包含包名、`/html-page/` 或部署前缀。

## 菜单

`06_menu/config.json` 注册三个一级入口：

| 名称 | 类型 | 参数 |
| --- | --- | --- |
| 插件能力实验室配置 | `POLICY_CONFIG` | `com.coolxer.plugin.lab.app` |
| 插件能力实验室 | `LOW_CODE_APP` | `com.coolxer.plugin.lab.app` |
| 实验室 IP 关联调查 | `LOW_CODE_PAGE` | `com.coolxer.plugin.lab.ip-investigation` |

安装只创建菜单，角色权限仍需在权限管理中分配。
