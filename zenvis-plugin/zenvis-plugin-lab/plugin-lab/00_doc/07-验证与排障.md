# 验证与排障

## 静态检查

```bash
find plugin-lab -name '*.json' -print0 | xargs -0 -n1 jq empty
head -n 1 plugin-lab/02_push-task/lab-demo-generator.yaml
head -n 1 plugin-lab/02_push-task/lab-kafka-to-clickhouse.yaml
```

两个 YAML 第一条物理行必须都是 `---`。还应检查：

- 实体 ID 与属性 ID 全局唯一；
- 无 `search_type`、`aggregate_link`、`zenvis_id`、`zenvis_insert_time` 定义；
- 分区全部为 `toYYYYMM(zenvis_insert_time)`；
- Vector 正常输出字段与 Meta 业务属性完全一致；
- 页面、详情链接、看板目录、菜单参数与配置索引一致；
- 包内无 `.DS_Store`、`target`、`build.log`、旧 JAR 或旧包名。

## 单元测试

```bash
mvn -f extend-lab/pom.xml test
```

测试覆盖 JSON snake_case 契约、笔记 CRUD/分页/统计、MCP 工具名称与只读注解、路由契约。

## Vector

有 Vector 环境时：

```bash
vector validate --no-environment lab-demo-generator.yaml
vector test lab-demo-generator.yaml
vector test lab-kafka-to-clickhouse.yaml
```

若无本地 Vector，至少完成 YAML 解析，并在部署环境执行同等验证。内置测试必须确认合法样例进入正常输出，非法字段进入 `.dropped`，DLQ Topic 与 Source Topic 不重叠。

## 浏览器

对 `lab-overview.html` 使用真实或拦截的完整数据，在 1920×1080、1366×708 和短高度视口检查：

- 根页面无纵向溢出；
- 六类 KPI、图例、底部内容完整可见；
- 长列表与能力矩阵在面板内部滚动；
- 缩放后 Canvas 重新绘制，不超出面板；
- 加载、空数据、部分失败、重试、最后更新和自动刷新状态正确。

可直接提取内联 JavaScript 做语法检查：

```bash
node --check /tmp/lab-overview.js
```

## 构建与归档

```bash
cd zenvis-plugin/zenvis-plugin-lab
./build.sh
tar -tzf com-coolxer-plugin-lab-1.0.1.tar.gz
```

归档根目录必须包含 `index.json`、最新 Meta、两个 YAML、UI、看板、菜单、MCP、RAG、Skill 和 `00_doc`；不得包含源码构建目录、多个 JAR、日志、归档或系统隐藏文件。

## 验收清单

- 两个推送任务均运行且 Kafka 可用时，安装后约 15 秒内 `lab_access_event` 与 `lab_risk_signal` 均出现数据；
- 四页低代码应用可打开，两个详情链接与 IP 链接有效；
- HTML 大屏与低代码看板均可从看板入口进入；
- 笔记可新增、编辑、删除、分页和状态统计；
- MCP 管理页发现两个工具，调用结果与 REST 一致且无写能力；
- `lab-kb` 构建成功，Skill 聊天入口可见并可引用知识库；
- 归档中不存在旧 `user-event` 身份或旧 JAR。

## 常见问题

| 现象 | 排查 |
| --- | --- |
| 页面没有事件数据 | 依次检查演示生成任务、`LAB_ACCESS_TOPIC`/`LAB_RISK_TOPIC` 中的消息、Kafka 消费任务状态和两表记录 |
| ClickHouse Sink 返回 400 | 查看 ClickHouse `system.query_log.exception`；常见原因是 DateTime64 收到带 `Z`/时区偏移的 RFC3339 字符串，应使用 `YYYY-MM-DD HH:MM:SS.mmm` |
| Kafka 持续进入 DLQ | 按 dropped `reason` 检查字段名、ISO8601 时间、枚举和数值范围 |
| 笔记页提示数据库不可用 | 检查 MySQL 迁移、`pluginMysqlJdbcTemplate` 和事务管理器 Bean |
| 笔记接口返回 `HttpMessageConversionException` | 检查响应 DTO 是否混入未注册序列化器的 `java.time` 类型；`LabNote` 的时间必须使用插件内 `LocalDateTimeTextSerializer` |
| MCP 显示未连接 | 检查 `lab` 配置、Bearer 请求头、动态 JAR 是否加载、SSE 路由和网络 |
| 知识库未构建 | 检查 Embedding/Redis、`lab-docs` 目录是否含 Markdown、知识库构建状态 |
| Skill 看不到工具 | 检查 Skill 白名单、MCP 全局开关、Agent Scope 和审批策略 |
| 看板请求 401 | 在 ZenVis 已登录页面打开；HTML 看板依赖当前登录 Session |
