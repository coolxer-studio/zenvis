# 旧功能到新示例的对照

本插件采用全新安装身份 `com.coolxer.plugin.lab`，不迁移旧 `com.coolxer.plugin.user.event` 数据，也不继续维护旧包。

| 旧 `user-event` 能力 | 新实验室示例 | 变化 |
| --- | --- | --- |
| 单实体 `user_event` | `lab_access_event` + `lab_risk_signal` | 从单表演示升级为可关联的双实体 |
| 表 `msg_user_event` | `lab_access_event`、`lab_risk_signal` | 表名与字段完全重命名 |
| 随机用户事件字段 | 访问行为字段 + 风险线索字段 | 增加字典、数组、JSON、数值评分和跨实体 IP |
| TOML 推送任务 | 两个 YAML 推送任务 | 演示生成与 Kafka/DLQ 分离 |
| 仅正常写入路径 | 正常写入 + 字段校验 + 统一 DLQ | 覆盖生产接入失败处理 |
| 无详情页 | 两个实体独立详情页 | 使用 `record_id` 和实体 view API |
| 无 IP 调查 | 独立 IP 调查页 | 跨实体源/目的 IP OR 匹配 |
| 简单用户管理页面 | 四页低代码应用 + 笔记 CRUD | 增加分页、筛选、状态统计、JSON 与表单 |
| 单 HTML 大屏 | HTML 大屏 + 低代码数据观察台 | 同时演示两种看板注册 |
| 旧菜单 | 配置、应用、独立页面三种菜单 | 覆盖 `POLICY_CONFIG`、`LOW_CODE_APP`、`LOW_CODE_PAGE` |
| 无动态数据库写操作 | 动态 REST API + MySQL 迁移 + 事务 | 展示薄 JAR、迁移和事务写入 |
| 空 MCP 配置 | `lab` 只读 MCP | 能力目录与笔记检索 |
| 无 RAG | `lab-docs` + `lab-kb` | 插件托管知识库 |
| 空 Skill 占位 | `lab-capability-guide` | 知识库、工具白名单、预算和降级 |

## 身份变化

| 维度 | 旧值 | 新值 |
| --- | --- | --- |
| 显示名称 | 用户事件示例 | 插件能力实验室 |
| 包名 | `com.coolxer.plugin.user.event` | `com.coolxer.plugin.lab` |
| Maven 工程 | `extend-user-event` | `extend-lab` |
| 插件目录 | `plugin-user-event` | `plugin-lab` |
| 发布包 | 旧用户事件归档 | `com-coolxer-plugin-lab-1.0.0.tar.gz` |

不要把旧数据库表、旧配置索引或旧菜单参数继续指向新插件。若环境中已经安装旧包，应按独立插件处理：先确认旧菜单、MCP、RAG 和 Skill 的清理策略，再安装新包。
