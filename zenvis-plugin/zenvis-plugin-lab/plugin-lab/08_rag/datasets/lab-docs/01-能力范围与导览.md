# 插件能力实验室范围与导览

插件能力实验室的包名是 `com.coolxer.plugin.lab`，版本 `1.0.0`。它用两个合成实体演示 ZenVis 插件的组合方式，目标是教学和接入验证，不是生产安全产品。

## 能力范围

| 能力 | 入口 | 说明 |
| --- | --- | --- |
| Meta | `01_meta/meta-lab.json` | 双实体、字典、数组、JSON、详情与 IP 链接 |
| 接入 | `02_push-task/` | 演示生成链路与 Kafka 到 ClickHouse/DLQ 链路 |
| REST/MySQL | `extend-lab/`、`03_api/migrations/mysql/` | 笔记 CRUD、分页、统计、迁移与事务 |
| 应用 | `04_ui/app/` | 总览、访问事件、风险线索、实验室笔记 |
| 详情 | `04_ui/detail-access-event/`、`04_ui/detail-risk-signal/` | 按 `record_id` 查询实体 view |
| IP 调查 | `04_ui/ip-investigation/` | 跨两个实体匹配源/目的 IP |
| 大屏 | `04_ui/html-page/lab-overview.html` | 真实聚合、趋势、分布、Top IP、事件与能力矩阵 |
| 看板 | `05_dashboard/config.json` | HTML 与低代码两种看板 |
| Agent | `07_mcp/`、`08_rag/`、`09_skill/` | 只读 MCP、知识库和导览 Skill |

## 推荐观察顺序

1. 先打开低代码应用总览，确认数据接入和页面可用；
2. 查看列表首字段的详情链接和 IP 链接；
3. 在 IP 调查页输入演示地址，比较两个实体的命中；
4. 在笔记页验证 CRUD 与状态统计；
5. 打开 HTML 大屏和低代码看板；
6. 在 MCP 与 Skill 管理页确认 Agent 能力。

所有 IP、事件、规则和风险分都是合成数据。跨实体 IP 关联只演示查询语义，不能解释为真实攻击因果。
