# 数据模型与字段

Meta 使用实体 ID `9401` 与 `9402`，属性 ID `940101–940112`、`940201–940211`。

## 实体

| 实体 | 表 | 排序字段 | 分区 |
| --- | --- | --- | --- |
| `lab_access_event` | `lab_access_event` | `occurred_at` | `toYYYYMM(zenvis_insert_time)` |
| `lab_risk_signal` | `lab_risk_signal` | `detected_at` | `toYYYYMM(zenvis_insert_time)` |

## 访问事件

`event_id:String`、`occurred_at:DateTime64(3)`、`actor:String`、`action:String`、`result:String`、`severity:String`、`source_ip:String`、`destination_ip:String`、`resource:String`、`trace_id:String`、`tags:Array(String)`、`detail:json`。

`action` 字典为 `login`、`read`、`write`、`execute`、`share`；`result` 为 `success`、`denied`、`failed`；`severity` 为 `info`、`low`、`medium`、`high`。`event_id`、源/目的 IP、资源和追踪 ID 可复制；首字段链接详情页，两个 IP 链接调查页。

## 风险线索

`signal_id:String`、`detected_at:DateTime64(3)`、`rule_code:String`、`severity:String`、`status:String`、`risk_score:Float64`、`source_ip:String`、`destination_ip:String`、`summary:String`、`tags:Array(String)`、`detail:json`。

`severity` 为 `low`、`medium`、`high`、`critical`；`status` 为 `open`、`investigating`、`resolved`、`accepted`；`risk_score` 范围为 0–100。`signal_id` 链接风险详情页，两个 IP 链接调查页。

## 存储边界

插件不定义 `zenvis_id` 或 `zenvis_insert_time`。前者由平台注入为记录 UUID，后者用于入库时间与分区。Vector 正常输出必须只包含业务属性，不能写入平台保留字段。
