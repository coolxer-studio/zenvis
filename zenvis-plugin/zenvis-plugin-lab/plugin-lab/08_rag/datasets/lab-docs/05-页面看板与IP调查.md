# 页面、看板与 IP 调查

低代码应用配置索引是 `com.coolxer.plugin.lab.app`，`site.json` 提供能力总览、访问事件、风险线索和实验室笔记四个入口。两个列表通过 `/zenvis/api/v1/entity/{entity}/list` 查询，笔记通过插件 REST API 查询。

独立页面索引：

- `com.coolxer.plugin.lab.detail-access-event`；
- `com.coolxer.plugin.lab.detail-risk-signal`；
- `com.coolxer.plugin.lab.ip-investigation`。

详情页从 Meta 首字段的 `{zenvis_id}` 取得 `record_id`，调用 `/zenvis/api/v1/entity/{entity}/{record_id}/view`。IP 调查页支持 `?ip=` 和手工输入，调用 `/zenvis/api/v1/entity/value-statistics/query`；每个实体的 `source_ip` 与 `destination_ip` 使用 OR 匹配，因此同一记录只计一次。

`05_dashboard/config.json` 同时注册 `HTML_PAGE` 大屏与 `LOW_CODE_PAGE` 数据观察台。HTML 文件位于 `04_ui/html-page/lab-overview.html`，低代码看板目录为 `05_dashboard/low-code/com.coolxer.plugin.lab.dashboard_config/`。

菜单覆盖三种类型：`POLICY_CONFIG` 与 `LOW_CODE_APP` 指向应用索引，`LOW_CODE_PAGE` 指向 IP 调查页。安装只创建入口，角色权限需单独分配。
