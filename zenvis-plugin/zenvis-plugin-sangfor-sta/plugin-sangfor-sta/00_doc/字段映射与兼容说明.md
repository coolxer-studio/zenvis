# 字段映射与兼容说明

## 源接口兼容项

- 源接口目录将 DHCP 写作 `dncp`，章节定义和样例使用 `dhcp`。本插件以 `dhcp` 为规范值，并在解析阶段兼容 `dncp`。
- 源字段包含 snake_case、camelCase、PascalCase、全大写和连字符。解析后统一转为小写 snake_case。
- DNS 响应同时定义 `answers` 摘要和 `Answers` 明细。后者规范化保存为 `answer_details`，避免大小写折叠冲突。
- 任何单条记录缺少字段、字段数量或类型不合法、JSON 非法、时间非法、布尔值非法或 `logtype` 不受支持时，整条记录进入 `STA_DLQ_TOPIC`，不会写入 ClickHouse。

## 类型策略

- Unix 秒时间戳写入 `DateTime`；文档明确为毫秒的 HTTP 会话字段写入 `DateTime64(3)`。
- 混合 IPv4/IPv6 地址使用 `String`；端口使用无符号整数；CRC、编号和计数按文档取值范围使用无符号整数。
- 文档明确声明的 JSON、数组和布尔值分别使用 `JSON`、`Array(String)` 和 `Bool`。
- 文档未要求 Base64 解码，密码、证书、报文和 XML 内容保持原值。
- 所有日志表沿用参考插件的 `MergeTree` 排序键和 TTL：50 类普通日志保留 1 天，RDP 爆破与 WAF/IPS/UTM/PVS 安全日志长期保留。

## 独立命名

- 插件包名：`com.coolxer.plugin.sangfor.sta`。
- 实体统一使用 `sangfor_sta_<logtype>`。
- ClickHouse 表统一使用 `zenvis.t_sangfor_sta_<logtype>`。
- 实体、字段和操作符 ID 使用独立区间，可与原 OneSOC 插件同时安装。

## 演示数据任务

- 独立任务 `02_push-task/sangfor-sta-demo-to-kafka.yaml` 从 STA V2.0 官方 55 类样例中随机选择一条生成消息，默认每 60 秒生成一条。
- 生成时刷新 `uid`、`ts`、`ds`、`hh`，并对 UTM 的 `nLevel` 以及 WAF/IPS/PVS 的 `level` 随机生成 1–4，便于页面展示时间分布和安全等级。
- 演示消息写入正式 `STA_SOURCE_TOPIC`，随后由正式入库任务执行相同的解析、路由、DLQ 和 ClickHouse 写入，不维护第二套映射或表结构。
- 生产间隔由 `SANGFOR_STA_DEMO_INTERVAL_SECONDS` 控制。该任务可单独启停；正式设备接入后应停止“深信服 STA 演示数据生成”，停止操作不影响正式入库任务或已写入的数据。
