# 用户事件菜单配置说明文档

## 菜单概述

该配置文件定义了用户事件相关的两个功能菜单项，分别指向不同的功能模块和页面，为用户提供数据可视化和分析能力。

## 菜单项详情

### 1. 用户事件可视化配置

| 属性 | 值 | 说明 |
|------|----|------|
| 菜单名称 | 用户事件可视化配置 | 用于管理用户事件低代码配置 |
| 路由地址 | `policy-config` | 系统内的路由标识 |
| 参数 | `com.coolxer.plugin.user.event` | 传递给页面的参数，标识插件命名空间 |
| 类型 | `POLICY_CONFIG` | 配置管理页面 |

### 2. 用户事件管理

| 属性 | 值 | 说明 |
|------|----|------|
| 菜单名称 | 用户事件管理 | 用于查询和管理真实用户事件数据 |
| 路由地址 | `low-code-page` | 系统内的路由标识，指向低代码平台页面 |
| 参数 | `com.coolxer.plugin.user.event` | 传递给页面的参数，标识插件命名空间 |
| 类型 | `LOW_CODE_PAGE` | 低代码单页面 |

## 功能说明

### 用户事件可视化配置
该菜单用于查看和维护插件安装的低代码页面配置。

### 用户事件管理
该菜单打开 `user_event` 实体管理页，支持真实列表查询、筛选、JSON 详情和记录维护。

## 技术说明

两个菜单项都使用参数 `com.coolxer.plugin.user.event`，分别通过 `POLICY_CONFIG` 和 `LOW_CODE_PAGE` 路由进入配置页与数据管理页。
